# BOOK OS — Decision Records

This directory stores bounded project decisions that need more detail than the canonical authority summary.

Rules:

1. Every record has a status: `PROPOSED`, `ACCEPTED`, `SUPERSEDED`, or `REJECTED`.
2. Accepted decisions are never silently rewritten.
3. If a decision changes, add a new record and explicitly supersede the old one.
4. `docs/BOOK_OS_AUTHORITY.md` remains the canonical high-level authority index.
