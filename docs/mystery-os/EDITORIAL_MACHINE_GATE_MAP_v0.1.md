# MYSTERY OS — EDITORIAL MACHINE GATE MAP v0.1

**Status:** INCUBATION DRAFT  
**Date:** 2026-09-18

## 1. Purpose

This document connects the MYSTERY OS standards into one executable editorial machine.

A book is not advanced because a model produced output. It advances only when required authority is fresh, required gates pass and human decisions are present where material.

## 2. Canonical production path

`IDEA -> MARKET -> SERIES POSITION -> STORY DEFINITION -> NARRATIVE CONTRACT -> CASE SOLUTION -> REALISM PLAN -> MYSTIC RULES -> CHARACTERS -> SUSPECT/CLUE/TIMELINE -> SCENE ARCHITECTURE -> REPRESENTATIVE SAMPLE -> WRITING -> MIDBOOK -> DEVELOPMENTAL REBUILD -> WHOLE-BOOK AUDITS -> PROFESSIONAL BENCHMARK -> LITERARY MASTER -> DERIVATIVES`

## 3. Gate A — Commercial premise

Required:
- target reader/subgenre;
- current market/comparable evidence;
- one-sentence premise;
- hook beyond trope labels;
- series position if applicable;
- anti-cliche concept scan.

Decision:
`GO | REWORK | HOLD | NO_GO`

Best execution:
- deterministic market data collection where possible;
- standard analyst for synthesis;
- premium/Astra/EDITORIAL_PREP when concept choice has major downstream impact or candidates are close.

Human approval required for final direction.

## 4. Gate B — Story authority

Required:
- approved StoryDefinition;
- GenreProfile;
- explicit exclusions;
- target length;
- series role;
- ending/satisfaction promise at abstract level.

Fail if:
- premise remains generic;
- core promise conflicts with market/genre;
- multiple blocked cliches underpin concept;
- narrative engine cannot sustain full length.

## 5. Gate C — Narrative authority

Required:
- approved NarrativeContract;
- viewpoint roster;
- tense/person;
- reliability model;
- withholding rules;
- culprit-POV rule if relevant;
- documentary/dream/vision rules if used.

Fail if:
- the proposed twist requires dishonest POV suppression;
- narrative mode exists only to hide information;
- voices/functions are not distinguishable.

Premium reasoning is justified for complex unreliable or multi-POV designs.

## 6. Gate D — Solved case

Required:
- approved CaseSolution;
- motive/means/opportunity;
- full objective sequence;
- concealment;
- unavoidable traces;
- proof chain independent of confession;
- intended ambiguity explicitly bounded.

Fail closed if culprit or decisive mechanism is still being improvised.

This is a high-blast-radius premium operation by default unless a cheaper executor has proven equal quality.

## 7. Gate E — Realism dependency plan

Required:
- fiction research dependencies identified;
- all R3/R4 plot-critical questions listed;
- jurisdiction/time context;
- intentional fictionalizations declared;
- dependent authority links established.

Writing may proceed before every low-risk detail is researched, but not while unresolved R3/R4 facts can break CaseSolution/Timeline/Clue logic.

## 8. Gate F — Supernatural authority

Only when material.

Required:
- MysticRuleSet;
- capability/limitation/trigger/cost/reliability;
- interaction with physical evidence;
- reader disclosure requirement;
- prohibited late expansions.

Fail if mysticism can deliver whatever clue the plot needs.

## 9. Gate G — Character and relationship authority

Required for primary/recurring cast:
- goals;
- contradictions;
- competencies/limits;
- fears/values;
- voice markers;
- CharacterArc;
- RelationshipArc;
- series continuity state.

Fail if characters remain functions/packages rather than causal actors.

High-impact recurring-character design may use premium comparative generation/evaluation.

## 10. Gate H — Investigation architecture

Required:
- suspects;
- secrets;
- clues;
- red herrings;
- EvidenceChains;
- CaseTimeline;
- NarrativeTimeline;
- RevealPlan;
- CharacterKnowledgeStates;
- ReaderKnowledgeState baseline.

Deterministic validators run before model judgment.

Fail for:
- impossible timeline;
- orphan decisive clue;
- false red herring with no underlying cause;
- solution stronger only because reader was denied necessary information;
- alternate culprit fits evidence better.

## 11. Gate I — Scene architecture

Each planned scene needs a fresh SceneContract.

Required:
- POV;
- time/location;
- entering/exiting state;
- purpose;
- knowledge state;
- clue/reveal operation;
- character/relationship movement;
- tension source;
- prohibited disclosure;
- factual dependencies;
- anti-cliche warnings.

Scene without state change is a deletion/merge candidate.

## 12. Gate J — Representative Fiction Sample

Before mass drafting, produce a bounded sample after authority is stable.

Suggested sample:
- opening;
- investigation/dialogue scene;
- tension/mystical scene where applicable;
- quiet character scene where useful.

Evaluate:
- NarrativeContract compliance;
- voice;
- POV integrity;
- dialogue;
- scene causality;
- suspense;
- anti-cliche drift;
- realism;
- audio readability;
- professional benchmark gap.

If materially weak, **do not scale weak prose to a whole manuscript**.

Revise StyleProfile, NarrativeContract, SceneContract design or model routing first.

## 13. Gate K — WRITING_ALLOWED

Every chapter/scene is admitted individually.

Fail closed before provider/model access when:
- authority is absent/stale;
- POV/knowledge is invalid;
- plot-critical research is unresolved;
- clue/reveal timing is illegal;
- a blocked cliche is unresolved;
- scene function is empty;
- requested model/cost path lacks authorization.

Most admitted scene drafting should use the least expensive proven Writer that can meet the approved sample quality.

## 14. Gate L — Chapter/scene QA

After writing:
- contract fulfillment;
- continuity;
- POV/knowledge;
- clue exposure;
- narrative fairness;
- dialogue/voice;
- research realism;
- anti-cliche/style pathology;
- repetition;
- listenability.

Failures trigger bounded revision, not blind full regeneration.

## 15. Gate M — Midbook audit

Mandatory structural stop.

Evaluate:
- case-model movement;
- clue balance;
- suspect viability;
- reader prediction state;
- character pressure;
- relationship movement;
- supernatural power drift;
- pacing/dead loops;
- repeated scene patterns;
- realism drift;
- NarrativeContract drift;
- professional benchmark trajectory.

Premium whole-context reasoning is justified here.

BLOCKING findings pause further Writing.

## 16. Gate N — Developmental rebuild

Do not protect sunk cost.

System may recommend:
- cut/merge scenes;
- rebuild motive;
- change suspect architecture;
- move/add/remove clues;
- rebuild midpoint;
- revise relationship progression;
- replace ending/climax staging.

Material authority changes create new versions and invalidate downstream work structurally.

## 17. Gate O — Whole-book technical mystery audit

Run:
- CaseSolution reconstruction;
- timeline feasibility;
- CharacterKnowledge audit;
- ReaderKnowledge/fair-play audit;
- clue lifecycle;
- RevealPlan fulfillment;
- MysticRuleSet integrity;
- research/realism audit;
- anti-cliche scan;
- series collision scan.

Deterministic failures cannot be averaged away by literary quality.

## 18. Gate P — Cold Reader / adversarial review

Cold Reader has no CaseSolution.

Adversarial evaluator reconstructs the case from manuscript alone.

Fail if:
- required facts are missing;
- another solution is materially stronger;
- final solution depends on late invention;
- reader confusion is accidental rather than productive;
- twist is obvious only because trope machinery is exposed.

## 19. Gate Q — Professional Fiction Benchmark

Compare the exact candidate to the curated benchmark set on:
- premise identity;
- engine;
- characters;
- scenes;
- dialogue;
- mystery construction;
- suspense;
- prose/voice;
- setting;
- emotional architecture;
- whole-book structure;
- originality;
- audio readiness.

Target before final release:
- no unresolved BLOCKING professional gap;
- material MAJOR gaps either fixed or explicitly human-disposed;
- readiness at least `PROFESSIONAL_RANGE_CANDIDATE` for a premium MYSTERY OS release target.

A label never overrides human literary judgment.

## 20. Gate R — Literary edit

Line/literary edit improves:
- precision;
- rhythm;
- viewpoint embodiment;
- dialogue distinction;
- image freshness;
- emotional restraint;
- transitions;
- repetition;
- audio flow.

It may not silently alter CaseSolution, clues, knowledge state or factual authority.

## 21. Gate S — Final release candidate

Bind exact revisions/hashes of:
- StoryDefinition;
- GenreProfile;
- NarrativeContract;
- CaseSolution;
- Character/Relationship authority;
- FictionResearchLedger snapshot;
- ClueLedger/EvidenceChains;
- CaseTimeline;
- MysticRuleSet where applicable;
- StyleProfile;
- final manuscript;
- final MysteryBench;
- Professional Fiction Benchmark run;
- Series Closure;
- human approval.

Only then create Literary Master.

## 22. Derived outputs

Text/audio/EPUB/PDF/platform packages derive from Literary Master or an explicitly accepted audio adaptation authority.

They cannot silently mutate upstream story truth.

## 23. Model-routing map

### Deterministic / local
- schemas;
- staleness;
- timeline conflicts;
- duplicate IDs;
- exact clue lifecycle;
- repeated phrases/patterns;
- revision binding;
- cost accounting.

### Standard Writer/Editor
- most admitted scenes;
- routine bounded revisions;
- local continuity fixes;
- structured extraction.

### Premium frontier / Astra-class
- concept selection when uncertain;
- series engine;
- CaseSolution;
- complex narrative architecture;
- clue/reveal architecture;
- difficult recurring-character arcs;
- midpoint audit;
- whole-book developmental review;
- professional benchmark diagnosis;
- final high-level literary diagnosis.

### Agents API / Codex `EDITORIAL_PREP`
Use for bounded multi-step preparation/adversarial packages when orchestration, tool use or structured artifact production materially helps.

Agent output is always `PROPOSED` until human acceptance.

## 24. Escalation rule

Start with the least expensive executor proven for the operation.

Escalate when:
- output fails the relevant gate repeatedly;
- task has high blast radius;
- ambiguity is genuinely hard;
- comparative evidence shows material quality gain;
- whole-book context requires stronger reasoning.

Do not escalate merely because a premium model exists.

Do not refuse escalation merely because it costs more when quality-critical.

## 25. Machine principle

MYSTERY OS is not a prompt chain.

It is:

`authority + dependencies + gates + selective execution + independent evaluation + human acceptance + reproducible release`.
