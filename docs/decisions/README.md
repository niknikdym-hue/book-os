# BOOK OS — Decision Records

This directory stores bounded, durable owner and architecture decisions when they are too detailed to live only in the main authority file.

Each accepted decision record should include:

- decision ID;
- date;
- status: `PROPOSED`, `ACCEPTED`, `REJECTED`, or `SUPERSEDED`;
- context/problem;
- decision;
- rationale;
- consequences / constraints;
- what it supersedes, if anything;
- links to affected authority/specification files.

Accepted decisions are never silently rewritten. A changed decision gets a new record and explicitly supersedes the previous one.
